26    /// Defines a new test, this must be done before attributes can be set via PGMSetAttr. Note that this doesn't

28    ///         ID,    Name,     Tester,       Library  Template

41    SetAttr(usize, String, Option<ParamValue>, bool),
42    /// Set the limit of the given test or invocation, (test_id, inv_id, hi/lo, value). Note that either test_id

44    SetLimit(Option<usize>, Option<usize>, LimitSelector, Option<Limit>),
45    /// Defines an additional named limit row for an existing test instance.
46    /// Parent test ID, name, optional test number, low limit, high limit.
47    DefSubTest(usize, String, Option<usize>, Option<Limit>, Option<Limit>),
48    /// Execute a test (or invocation) from the flow
49    Test(usize, FlowID),
50    /// Execute a test (or invocation) from the flow, where the test is simply a string to be inserted
51    /// into the flow

53    TestStr(String, FlowID, Option<usize>, Option<usize>, Option<usize>),

55    PatternGroup(usize, String, SupportedTester, Option<PatternGroupType>),

57    PushPattern(usize, String, Option<String>),

59    Render(String),

61    Log(String),

63    Group(String, Option<SupportedTester>, GroupType, Option<FlowID>),

112    FlowData(FlowData),

114    /// A typed data variable declaration: (name, type_name, initial_value).
115    /// Used for declaring local or global variables in any tester format that supports them
116    /// (e.g. V93K SMT8 variable sheets), not to be confused with the flow-control flag
117    /// variables tracked in the Model.
118    Variable(String, String, Option<String>),

120    /// A step or node whose type is not specifically recognized by the current processor.
121    /// Carries the original type name and raw identifying data so it can be passed through
122    /// losslessly and reconstructed by an importer. (step_type_name, raw_data)

125    /// A source-level documentation comment. Does not execute at runtime.
126    /// Distinct from Log (which is a runtime output statement). Used to annotate
127    /// the generated flow source in formats that support inline comments/descriptions.
128    Comment(String),
129
130    /// A timed delay/wait step. Duration is a format-agnostic string
131    /// (e.g. "1s", "500ms", "1.5e-3"). Processors targeting testers with
132    /// timing support should emit the appropriate wait primitive; others should
133    /// pass it through unchanged.
134    Wait(String),

136    /// Variable assignment: (variable_name, value_expression).
137    /// Complements Variable (declaration) — assigns a new value to an existing
138    /// variable. The value_expression may be a literal or a tester-specific
139    /// expression string.
140    SetVariable(String, String),

142    /// Flow input/output parameter declaration: (name, type_name, default_value).
143    /// Distinct from Variable (local variable). Represents a named, typed parameter
144    /// of a SubFlow — analogous to a function argument. Used in formats with named
145    /// parameter declarations such as SMT7.
146    Parameter(String, String, Option<String>),

148    /// Multi-site synchronization barrier. Processors targeting testers that support
149    /// multi-site execution should emit the appropriate sync primitive (e.g. V93K
150    /// synchronization). Processors that don't understand this node should pass it
151    /// through unchanged.
152    Synchronize,
153
154    /// A labeled jump target. Formats that support labeled flow control use this to mark
155    /// a named jump destination. Complemented by Goto.
156    Label(String),
157
158    /// Jump to a labeled target. Formats that support labeled flow control use this to

160    Goto(String),

162    /// Events to run if the test or group with the given ID produced a runtime error
163    /// or abort (not a test failure). Completes the result-handler triad alongside
164    /// OnPassed and OnFailed. Processors that don't handle this should pass it through.
165    OnError(FlowID),
166
167    /// An external procedure/subroutine call with positional arguments: (procedure_name, args).
168    /// Distinct from SubFlow (which is flow-graph-aware and tracked by the Model).
169    /// Used for calling external procedures, library routines, or user-defined subroutines
170    /// that are not part of the flow graph. Processors that don't handle this should pass
171    /// it through unchanged.
172    Call(String, Vec<String>),
173
174    /// A bounded iteration loop: (iteration_count, counter_variable_name).
175    /// `iteration_count` is None for condition-driven or infinite loops.
176    /// `counter_variable_name` is None if the loop counter is not exposed as a variable.
177    /// Child nodes form the loop body. Fills the gap left by the payload-less Whenever* placeholders
178    /// for formats with explicit loop constructs (e.g. SMT7 loops).
179    Loop(Option<u32>, Option<String>),
180
181    /// A structured result report entry: (category, message).
182    /// Distinct from Log (runtime stdout) and Comment (source annotation).
183    /// Produces structured output that becomes part of the test result record.
184    /// Used by formats like SMT8 result annotation steps.
185    Report(String, String),
186
187    /// A runtime assertion: (expression, failure_message).
188    /// If the expression evaluates to false at runtime, execution halts with an error
189    /// (not a test failure). Distinct from Test (which measures a DUT) and Condition
190    /// (which branches). Used for program-correctness checks and defensive assertions.
191    Assertion(String, String),
192
193    /// A named hook or callback invocation with positional arguments: (callback_name, args).
194    /// Used for formats where callbacks are first-class flow steps. Processors that don't
195    /// handle this should pass it through unchanged.
196    Callback(String, Vec<String>),
