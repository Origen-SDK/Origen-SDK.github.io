pub fn to_addr_trans(&self, default_addr_size: Option<usize>) -> Result<Self>

Shortcut function to generate a new transaction where the address of this transaction acts as the data of the new one. The address_width field will be the new transaction’s width. If this is not provided, it will be taken from the default_addr_size. If neither widths are provided, or if the address width exceeds the resolved width, an error is returned.
