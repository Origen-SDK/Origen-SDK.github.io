fn populate(&self, version: &str) -> Result<()>

Initially populate the local directory with the remote, this is equivalent to a ‘git clone’ or a ‘dssc pop’ operation. A progress instance will be returned indicating how many objects were fetched. A callback can be given which will be called periodically if the caller wants to be updated on the progress during the operation.

Source

fn checkout( &self, force: bool, path: Option<&Path>, version: &str, ) -> Result<bool>

Checkout the given version of the repository. If force is false then local modifications will be preserved and merged with any upstream changes. If merge conflicts are encountered then this method will return Ok(true)

Source

fn revert(&self, path: Option<&Path>) -> Result<()>

Reverts any local changes. Supplying a path to a directory may be supported to limit the results to files that fall withing the given directory.

Source

fn status(&self, path: Option<&Path>) -> Result<Status>

Returns a Status object which contains lists of all files which have local modifications. Supplying a path to a directory may be supported to limit the results to files that fall withing the given directory.

Source

fn tag(&self, tagname: &str, force: bool, message: Option<&str>) -> Result<()>

Tag the view in the local workspace. A tag message can be supplied, but this may or may not be applied to the repo depending on whether the underlying system supports it. Supplying force: true will replace any existing tag with the same name.

Source

fn init(&self) -> Result<Outcome>

Initialize a new local workspace at path, pointing to the given location Returns true if a new workspace was created, false if the workspace already existed (no action), or an error.
