Fields§

§target_testers: Vec<TesterSource>

This is the testers that have been selected by the current target, it will be cleared and new testers will be pushed to it during a target load. It contains references to both Rust and Python domain testers.

§stats: Stats

Keeps track of some stats, like how many patterns have been generated, how many with diffs, etc.
